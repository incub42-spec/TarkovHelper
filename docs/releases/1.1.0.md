# TarkovHelper 1.1.0

Опубликован 2026-08-17 · https://github.com/incub42-spec/TarkovHelper/releases/tag/v1.1.0

- Своя иконка приложения (боец ЧВК в шлеме и гарнитуре)
- Проект переведён на лицензию GPL-3.0
- Из прошлой версии: рамка области сканирования включается галочкой «отладка OCR» в настройках

**Скачай TarkovHelper.exe ниже — установка не нужна, просто запусти.**

Горячие клавиши: **F9** — предмет под курсором, **F10** — уровни станций убежища.

⚠️ **Статус обкатки:** проверку боем прошло пока только сканирование предметов (F9). Сканирование убежища (F10), авто-отметка квестов по логам и актуальность их списков работают, но ещё обкатываются — неточности можно поправить вручную во вкладках «Квесты» и «Убежище».
