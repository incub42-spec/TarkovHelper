# TarkovHelper 1.0.0

Опубликован 2026-08-17 · https://github.com/incub42-spec/TarkovHelper/releases/tag/v1.0.0

Первый релиз помощника по луту для Escape from Tarkov.

Горячие клавиши: **F9** — предмет под курсором, **F10** — уровни станций убежища. Автоматически отмечает сданные квесты по логам игры; база обновляется раз в сутки.

ℹ️ Есть более свежая версия — смотрите последний релиз.
