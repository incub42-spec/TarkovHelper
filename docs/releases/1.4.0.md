# TarkovHelper 1.4.0

Опубликован 2026-08-17 · https://github.com/incub42-spec/TarkovHelper/releases/tag/v1.4.0

**Русские названия новых квестов и предметов.** После выхода сезона BSG переработала множество квестов, и свежий контент показывался по-английски (или вовсе сырым идентификатором) — базы локализации за ним не успевают. Теперь недостающие названия подтягиваются с вики через межъязыковые ссылки: например, `69ce21e990144e437802b1e0` → «Обновление ассортимента». Квестов с русскими именами стало 509 из 517, предметов — 4533 из 4931. Результат кешируется, так что вики опрашивается только для нового.

**Режим PvE.** Настройки → «Режим PvE»: у PvE и PvP разные наборы квестов (в PvE, к примеру, нет событийных «Neuanfang») и свои цены. Раньше всем показывался список PvP — если играете в PvE, включите галочку, база перезагрузится под ваш режим.

**Устойчивость к пропаже источников.** Базы SPT и TarkovTracker стали необязательными: если они исчезнут, приложение продолжит работать — названия возьмутся с вики, а игровые данные из json.tarkov.dev.

**Из версии 1.3.0:** обновление приложения прямо из настроек (проверка версии при каждом запуске), названия для предметов новее наших баз — в базе стало 4931 предмет вместо 3783.

**Скачай TarkovHelper.exe ниже — установка не нужна, просто запусти.** Горячие клавиши: **F9** — предмет под курсором, **F10** — уровни станций убежища; в настройках переназначаются на любую клавишу или кнопку мыши.

Совет по точности: наведи курсор на предмет, дождись, пока игра покажет его подпись, и только тогда жми клавишу.

⚠️ **Статус обкатки:** проверку боем прошло пока только сканирование предметов. Сканирование убежища и авто-отметка квестов по логам работают, но ещё обкатываются — неточности правятся вручную во вкладках «Квесты» и «Убежище».
