# TarkovHelper 1.3.0

Опубликован 2026-08-17 · https://github.com/incub42-spec/TarkovHelper/releases/tag/v1.3.0

**Обновление прямо из приложения.** Настройки → «Обновление»: приложение само проверяет версию при каждом запуске, а по кнопке скачивает новую и перезапускается. Прогресс и настройки сохраняются. Скачивать exe вручную больше не нужно.

**Исправлены названия новых квестов и предметов.** Квесты, вышедшие после обновления баз локализации, показывались сырым идентификатором вроде `69ce21e990144e437802b1e0` — теперь имя достаётся из ссылки на вики (в примере это «Fresh Stock»). У предметов та же болезнь была ещё незаметнее: новые предметы молча выпадали из базы и вообще не распознавались. Теперь имя берётся из самого дампа данных, который всегда актуален.

**В базе стало 4931 предмет вместо 3783** — больше тысячи предметов, которые раньше терялись, теперь распознаются по F9.

**Скачай TarkovHelper.exe ниже — установка не нужна, просто запусти.** Горячие клавиши по умолчанию: **F9** — предмет под курсором, **F10** — уровни станций убежища; в настройках их можно переназначить на любую клавишу или кнопку мыши.

Совет по точности: наведи курсор на предмет, дождись, пока игра покажет его подпись, и только тогда жми клавишу — сканер в первую очередь читает именно тултип.

⚠️ **Статус обкатки:** проверку боем прошло пока только сканирование предметов. Сканирование убежища, авто-отметка квестов по логам и актуальность их списков работают, но ещё обкатываются — неточности можно поправить вручную во вкладках «Квесты» и «Убежище».
