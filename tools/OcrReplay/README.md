# OcrReplay — прогон распознавания по сохранённым кадрам

Приложение сохраняет каждый кадр, ушедший в OCR, в
`%AppData%\TarkovHelper\debug\scan-*.png` (последние 30). Этот инструмент
прогоняет по ним распознавание и сопоставление с базой — без игры и без
повторного сканирования. Так проверяется, что правка что-то починила и
ничего не сломала.

```
dotnet run --project tools/OcrReplay -- "%AppData%\TarkovHelper\debug\scan-212401-138-p1.png"
```

Кадры прохода 1 (`-p1`) сняты по правилу «курсор минус 480 по X и 185 по Y»,
поэтому положение курсора в кадре известно и веса по близости считаются так же,
как в оверлее. Для `-p2`/`-p3` смещения другие, и результат будет неточным.

Что повторяется один в один: два движка OCR (русский и английский), отсев
коротких меток ячеек, веса по расстоянию до курсора, склейка соседних строк
в две и три, порог 0.62. Матчер и модель подключены прямо из проекта, так что
разойтись они не могут.

Сравнить с прошлым поведением можно по `%AppData%\TarkovHelper\item-ocr-debug.log`:
в нём записано, что было принято на тех же кадрах раньше.
